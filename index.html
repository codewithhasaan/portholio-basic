Learn the fundamental concepts behind the Internet and World Wide Web.

1. The Internet

The Internet is a global network of interconnected computer networks that communicate using standard protocols such as TCP/IP.

It connects computers, servers, smartphones, networks, and other devices around the world.

Important Points

  • ARPANET (1969): One of the earliest operational packet-switching networks and an important predecessor of today's Internet.
  • The Internet connects millions of devices worldwide.
  • It supports services such as the Web, email, online gaming, streaming, and file sharing.

2. The World Wide Web (Web)

The World Wide Web (WWW) is a collection of interconnected digital resources that are accessed through the Internet.

The Web allows users to access web pages using hyperlinks.

  • Invented by Tim Berners-Lee in 1989.
  • Uses technologies such as HTML, HTTP, URLs, and web browsers.
  • The Web is a service that operates over the Internet.

Visit the World Wide Web Consortium (W3C) .

3. W3C — World Wide Web Consortium

The World Wide Web Consortium (W3C) develops international standards and recommendations for the Web.

Examples of Web Standards

  1. HTML
  2. CSS
  3. Web Accessibility
  4. Web Architecture

The official W3C website is: www.w3.org

4. Web Page

A web page is a single document available on the Web, usually created using HTML.

Example: https://example.com/about.html

The About page can be considered one individual web page.

5. Website

A website is a collection of related web pages and resources available under a common domain.

Example: www.example.com

A Website May Contain:

  • Home Page
  • About Page
  • Contact Page
  • Services Page
  • Blog Pages

6. Home Page

The home page is generally the main or introductory page of a website.

It normally provides navigation to other important sections.

Example: Example Home Page

7. Index Page

An index page is commonly the default page served when a directory or website location is accessed.

Typical File Names

  • index.html
  • index.php
  • index.htm
Important: A home page and an index page are related concepts, but they are not necessarily identical.

8. Landing Page

A landing page is a web page designed for a specific purpose, often after a user clicks an advertisement, email link, or search result.

Typical Goals

  • Register for a course
  • Buy a product
  • Download an application
  • Submit a form

9. Web Browser

A web browser is software used to access and display web pages.

Examples

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

A browser sends requests to web servers and renders the returned content.

10. Web Server

A web server is a computer system and software that stores, processes, and delivers web resources to clients.

Common Web Server Software

  • Apache
  • Nginx
  • Microsoft IIS

Basic Communication

Web Browser ───── HTTP/HTTPS Request ─────> Web Server

Web Browser <──── HTTP/HTTPS Response ──── Web Server

11. Web Domain

A domain name is a human-readable name used to identify a website or Internet service.

Example: www.example.com

Instead of remembering an IP address such as 93.184.216.34, users can use a domain name.

12. URL — Uniform Resource Locator

A URL specifies the location of a resource and how to access it.

Example URL

https://www.example.com:443/about/index.html?topic=web#section1
Part Example Purpose
Scheme https Protocol used to access the resource
Domain www.example.com Identifies the host
Port 443 Network port
Path /about/index.html Identifies the resource path
Query ?topic=web Provides additional parameters
Fragment #section1 Points to a section of the resource

13. URI — Uniform Resource Identifier

A URI is a broader concept used to identify a resource.

A URL is a type of URI.

Simple Distinction

  • URI: Identifies a resource.
  • URL: Identifies a resource and indicates its location/access method.

14. HTTP — HyperText Transfer Protocol

HTTP is the protocol used for communication between web clients and servers. 

Browser → HTTP Request → Server

Browser ← HTTP Response ← Server

HTTP commonly uses port 80.

15. HTTPS — HyperText Transfer Protocol Secure

HTTPS is HTTP communication protected using modern cryptographic security, primarily through TLS.

HTTPS Provides:

  • Encryption
  • Authentication
  • Data integrity

HTTPS commonly uses port 443.

16. SSL — Secure Sockets Layer

SSL was an earlier security protocol designed to secure network communication.

Important: SSL has been deprecated and replaced by TLS. Modern HTTPS uses TLS rather than SSL.

17. TLS — Transport Layer Security

TLS is the modern cryptographic protocol used to secure communications such as HTTPS.

Simplified TLS Model

Client
|
\| Secure Connection
↓
TLS Handshake
|
\| Encrypted Communication
↓
Web Server

18. HTML — HyperText Markup Language

HTML is the standard markup language used to structure web pages.

Basic HTML Boilerplate

<!DOCTYPE html>
<html>
<head>

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<meta charset="utf-8">

<title>Web Page</title>

</head>

<body>

<h1>Hello World</h1>

</body>
</html>

HTML uses elements and tags to structure content such as headings, paragraphs, images, lists, tables, and hyperlinks.

19. IP Address

An IP address is a numeric address that identifies a device on the Internet or a local network.

Examples

  • IPv4: 192.168.1.10
  • IPv6: 2001:db8::1

A domain name can be resolved to an IP address so that network communication can take place.

20. DNS — Domain Name System

DNS translates human-readable domain names into IP addresses and performs other naming functions.

Example

www.example.com
↓
DNS
↓
93.184.216.34

DNS makes it easier for people to use domain names instead of numeric IP addresses.

21. NSlookup / nslookup

nslookup is a command-line tool used to query DNS information.

Example Command

nslookup example.com

It Can Help Determine:

  • IP addresses associated with domains
  • DNS server information
  • DNS records

22. Search Engines

A search engine is a service that helps users find information and web pages on the Internet.

Examples

  • Google
  • Bing
  • DuckDuckGo

Basic Process

  1. User enters a query.
  2. Search engine processes the query.
  3. Search index is checked.
  4. Relevant results are displayed.
  5. User selects a result.

23. ChatGPT

ChatGPT is an AI-based conversational system developed by OpenAI.

It can understand natural-language prompts and generate responses, explanations, summaries, code, and other content.

Important Distinction:

A search engine primarily helps users find existing information, while ChatGPT primarily generates responses based on its model and available information and tools.

Learn more at: ChatGPT

24. Hyperlinks / Links

A hyperlink is a clickable reference that connects one resource to another.

HTML Example

<a href="https://example.com">
Visit Example
</a>

Links Can Connect:

  • One web page to another
  • One section to another
  • A website to another website
  • A page to a file or other resource

Example: Visit Example Website
